# Cocos Creator 2.4.15 原生层与 JSB

先阅读 [JSB 与原生源码导览](references/flow.md)，再选定一个具体的脚本接口或对象。依次追踪注册过程、参数与返回值转换、目标 C++ 方法，以及所有权或终结处理。确认目标平台实际使用该原生绑定；仅凭 JS API 名称不足以判断。

修改原生代码时，同时检查绑定层与实现层，并在对应原生平台上验证。若无法构建原生版本，应提供源码分析，并明确标注运行效果尚未验证。区分生成的 `auto/` 绑定与手写的 `manual/` 代码；未追溯生成器前，不要直接修改生成结果。

遵守 `2.4.15/AGENTS.md` 中的源码快照边界。若问题重点是绘制提交，使用渲染技能；[第四阶段学习文档](../../../docs/stage-04-native-and-rendering.md) 仅用于学习练习。
