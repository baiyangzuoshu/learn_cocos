# Cocos Creator 2.4.15 启动与生命周期

本技能用于继续分析启动、帧调度和场景激活。引擎源码位于工作区根目录下的 `2.4.15/resources/engine/`。在该安装快照内工作时，遵循 `2.4.15/AGENTS.md`。

分析启动或帧循环时，先读[已核对的入口图](references/flow.md)，再追踪用户所处环境对应的分支。分析场景或组件时，从 `CCDirector.loadScene()` 追到场景激活与组件调度；若问题涉及资源加载或旧场景释放，同时使用资源管理技能。

给出精确调用顺序前，核对本地源码中的关键函数。区分 `CC_EDITOR` 主进程、预览、Web 运行时与 JSB。陈述源码事实时注明文件和函数；尚未运行验证的预期行为要标为推断。修改代码时保持周边模块风格，并在独立项目或引擎副本中做最小相关验证。

仅在用户要求学习或评估本主题时，读取[阶段一学习计划](../../../docs/stage-01-engine-and-scene.md)。
