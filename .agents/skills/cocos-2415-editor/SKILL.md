# Cocos Creator 2.4.15 编辑器扩展

提出 API 方案前，先读[可见的编辑器扩展地图](references/flow.md)。区分扩展主进程代码、面板代码、编辑器环境使用的引擎代码，以及 `resources/app.asar` 中的代码。扩展模板只能证明消息通信与面板注册方式，不能据此推断任意场景编辑 API。

开发扩展时，从扩展清单、消息入口和面板交互入手。场景或资源数据库方法应在此安装版本的源码或可运行的最小扩展中验证，再声称其可用。批量修改场景前先校验输入及资源身份；重复执行的结果应可预测，错误信息应能定位到具体条目。

安装快照及 `.meta`/UUID 的工作边界见 `2.4.15/AGENTS.md`。除非用户明确要求修改安装包，否则在独立 Creator 项目中开发扩展。仅在学习练习中读取[阶段三学习计划](../../../docs/stage-03-editor-automation.md)。
